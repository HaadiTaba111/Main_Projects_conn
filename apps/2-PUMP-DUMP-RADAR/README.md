# Pump/Dump Radar Lab 🚨

رادار مستقل پامپ/دامپ؛ بدون وابستگی runtime مشترک با اتوتریدر. سرور روی پورت `8790` اجرا می‌شود و تنظیمات و وضعیت Paper را در مرورگر نگه می‌دارد.

## اجرا

از ریشهٔ مخزن:

```bash
node apps/2-PUMP-DUMP-RADAR/server.js
```

یا از پوشهٔ برنامه:

```bash
cd apps/2-PUMP-DUMP-RADAR
node server.js     # http://localhost:8790
```

Node.js 18+ کافی است؛ `npm install` لازم نیست.

## دریافت خودکار دیتا و اتوترید

- حلقهٔ اسکن خودکار پس از پایان هر اسکن دوباره زمان‌بندی می‌شود (بدون هم‌پوشانی)، پس خطای گذرا حلقه را نمی‌خواباند.
- کلاینت دیتا اول پراکسی هم‌مبدأ سرور (`/api/market/...`) را امتحان می‌کند و بعد درخواست مستقیم مرورگر؛ زنجیرهٔ منبع: Bybit → Binance → OKX → CoinGecko.
- رفرش دستی («پول فوری») فاصلهٔ زمانی و کش کندل‌ها را دور می‌زند.
- ورود خودکار مجازی مشروط به عبور از گیت‌های امتیاز/RSI/حجم/ریسک است؛ هر رد با علت شفاف روی کارت نماد می‌آید و نبود معامله در یک بازه به‌معنای خرابی نیست.

## معماری

- `server.js` — سرو فایل‌های ایستا، APIهای `/api/health` و پل اختیاری `/api/hot` و پراکسی دیتای بازار روی `/api/market/...` با allowlist ثابت (Node خالص).
- `src/js/services/radar.js` — اسکن بازار Bybit Linear با fallback به Binance، OKX و CoinGecko؛ فیلتر نماد/حجم و پنجرهٔ کشف از تنظیمات.
- `src/js/services/ignition.js` — ارزیابی کندل و مومنتوم و ساخت سیگنال LONG/SHORT یا WAIT.
- `src/js/services/paper-broker.js` — Paper trading با کارمزد، محدودیت‌های ریسک، حد ضرر/سود و Max Hold.
- `src/js/app.js` و `src/js/ui/` — حلقهٔ برنامه و داشبورد رادار، سیگنال‌ها، معاملات و تنظیمات.

## پل اختیاری به اتوتریدر (`apps/1-AUTOTRADE-FUTURES-PWA/`)

اگر `bridgePublish` در رادار و `pumpBridgeUrl` در اتوتریدر را خودت روشن کنی، نمادهای داغ از طریق `/api/hot` منتشر و خوانده می‌شوند. هر دو خاموش‌اند مگر با تنظیم صریح؛ اپ‌ها به‌طور پیش‌فرض مستقل می‌مانند.

## تست

```bash
npm test       # تست‌های منطق رادار، Ignition، Paper Broker، اعتبارسنج و UI
npm run check  # بررسی نحو ماژول‌ها
```

برای تست‌ها هم `npm install` نیاز نیست؛ این پروژه به پکیج خارجی وابستگی ندارد.

## نکتهٔ مهم

در صورت خطای شبکه، نمادها `DATA ERROR` می‌شوند و دیتای ساختگی جایگزین نمی‌شود. تست و Paper trading سودآوری آینده را تضمین نمی‌کنند.

سرور بدون احراز هویت است و روی همهٔ رابط‌های شبکه گوش می‌دهد؛ آن را فقط روی شبکهٔ مورداعتماد اجرا کن و پورتش را به اینترنت عمومی تونل نکن.
