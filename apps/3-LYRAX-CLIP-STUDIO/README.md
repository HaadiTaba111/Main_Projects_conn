# LyraX Clip Studio

استودیوی تحت وب برای همگام‌سازی لیریکس، مدیریت لایه‌های مستقل افکت، رندر واقعی FFmpeg و بسته‌بندی کامل پروژه برای انتقال بین گوشی و PC.

## امکانات اصلی

- زمان شروع و پایان **هر ردیف جدول زمان‌بندی** با دقت `0.001s` (یک میلی‌ثانیه)، ورودی مستقیم، دکمه‌های `+ / −` و کلیدهای `+ / -` یا جهت‌نمای بالا/پایین.
- توقف پخش زنده، زمان فعلی را به‌عنوان پایان برش ذخیره می‌کند؛ رندر بعدی (WebM سریع یا MP4 نهایی FFmpeg) فقط تا همان زمان ادامه می‌یابد. گزینه‌ی «رندر کل آهنگ» برش را پاک می‌کند.
- دکمه‌ی «رندر MP4 نهایی با FFmpeg» در خود جدول: رسانه‌ها به Flask ارسال می‌شوند، job رندر پیگیری می‌شود و خروجی H.264/AAC برای دانلود آماده می‌شود. ZIP پس از رندر اختیاری است تا دریافت MP4 مستقیم و روشن باشد.
- ZIP کامل شامل `project.json` قابل‌استفاده در بک‌اند، اکولایزر صدا، واترمارک، preset زیرنویس، لایه‌ها و زمان‌بندی افکت‌ها، لیریکس، صوت، پس‌زمینه، تصویرهای overlay، PNG ماسک و خروجی رندر (اگر موجود باشد).
- Lightning و Fireworks افزونه‌ای و مستقل هستند؛ پایان trigger قابل ویرایش است و در preview و خروجی FFmpeg اعمال می‌شود.
- **مکعب سه‌بعدی لیریکس (LyraX Cube):** بسته‌ی `lyrax-3d-cube` داخل خود استودیو ادغام شده است. مکعب یک پریست در منوی «✨ استایل انیمیشن لیریکس» است («🎲 مکعب چرخان از پایین به بالا»): فقط وجه خط جاری متن دارد، با هر خط ۹۰ درجه رو به بالا می‌چرخد و با `Space`/`→` خط بعدی می‌آید. چون روی بوم رسم می‌شود، در خروجی WebM/MP4 هم دیده می‌شود. صفحه‌ی مستقل مکعب (با خروجی WebM و پخش آهنگ) سر جای خودش است: `/static/cube-studio/index.html`.
- **استودیوی مستقل مکعب:** صفحه‌ی کامل مکعب لیریکس با پخش آهنگ، تشخیص خط فعال و خروجی WebM (۱۰۸۰×۱۹۲۰) در مسیر `/static/cube-studio/index.html` (لینک «🎲 استودیوی مکعب لیریکس» در هدر استودیو).
- نسخه‌ی Flask که اجرا می‌شود `templates/index.html` است؛ فایل `studio.html` هم باید با آن همگام نگه داشته شود.

## اجرای خودکار روی Termux

در Termux دستور زیر را اجرا کنید. اسکریپت Git، Python و FFmpeg بومی Termux را نصب می‌کند، مخزن/شاخه را clone می‌کند، محیط `.venv` می‌سازد، وابستگی‌های سازگار با Android را از `requirements-termux.txt` نصب و Flask را اجرا می‌کند؛ بنابراین نیازی به build شدن نسخه‌ی Rust کتابخانه‌ی bidi نیست:

```bash
pkg update -y && pkg install -y curl
export LYRAX_BRANCH="arena/01a10c56-main-arena-conn"
curl -fsSL "https://raw.githubusercontent.com/HaadiTaba111/Main_Arena_conn/${LYRAX_BRANCH}/apps/3-LYRAX-CLIP-STUDIO/bootstrap_termux.sh" | bash
```

پس از شروع سرور، در مرورگر همان گوشی باز کنید:

```text
http://127.0.0.1:5000
```

برای توقف، به Termux برگردید و `Ctrl+C` بزنید. اگر برنامه قبلاً clone شده، مسیر یا مخزن دیگری می‌خواهید، پیش از اجرای اسکریپت `LYRAX_INSTALL_DIR` یا `LYRAX_REPO_URL` را تنظیم کنید. فایل `bootstrap_termux.sh` را هم می‌توانید از پوشه‌ی برنامه اجرا کنید.

## اجرای خودکار در Windows PC

در PowerShell (با Git و Python 3 نصب‌شده) اجرا کنید:

```powershell
$env:LYRAX_BRANCH = 'arena/01a10c56-main-arena-conn'
$url = "https://raw.githubusercontent.com/HaadiTaba111/Main_Arena_conn/$($env:LYRAX_BRANCH)/apps/3-LYRAX-CLIP-STUDIO/bootstrap_pc.ps1"
Invoke-Expression (Invoke-RestMethod $url)
```

یا پس از clone/استخراج مخزن روی فایل `bootstrap_pc.bat` دوبار کلیک کنید. اسکریپت PowerShell محیط مجازی را می‌سازد، وابستگی‌ها را نصب و سرور را اجرا می‌کند. سپس آدرس `http://127.0.0.1:5000` را باز کنید و پنجره‌ی PowerShell را تا پایان کار باز نگه دارید.

## اجرای خودکار در Linux / macOS PC

به Git و Python 3 نیاز است:

```bash
export LYRAX_BRANCH="arena/01a10c56-main-arena-conn"
curl -fsSL "https://raw.githubusercontent.com/HaadiTaba111/Main_Arena_conn/${LYRAX_BRANCH}/apps/3-LYRAX-CLIP-STUDIO/bootstrap_pc.sh" | bash
```

برای نصب دستی/اجرای دوباره، از پوشه‌ی برنامه `./start_clip_studio.sh` را اجرا کنید. در Windows نیز `start_clip_studio.bat` اجراکننده‌ی محیط نصب‌شده است.

> اگر پروژه در شاخه‌ی اصلی ادغام شد، مقدار `LYRAX_BRANCH` را به `main` تغییر دهید. اجرای دستورهای `curl` بالا به قابل‌دسترسی بودن شاخه‌ی انتخاب‌شده در GitHub نیاز دارد.

## مکعب سه‌بعدی لیریکس (LyraX Cube)

دو راه برای استفاده از مکعب وجود دارد:

۱. **داخل استودیو، به‌عنوان پریست استایل لیریکس:** در کادر «✨ استایل انیمیشن و ترنزیشن لیریکس»، گزینه‌ی **«🎲 مکعب چرخان از پایین به بالا»** را انتخاب کنید. مکعب روی خود بوم/کلیپ رسم می‌شود:

- فقط **وجه خط جاری** متن دارد؛ بقیه‌ی وجه‌ها خالی‌اند.
- با هر خط، مکعب ۹۰ درجه **رو به بالا** می‌چرخد؛ خط جاری رو به بالا می‌رود و خط بعد از **پایین** می‌آید.
- **با کلید، لیریکس بعدی می‌آید:** `Space`/`Enter`/`→`/`↓` خط بعد، `←`/`↑` خط قبل — هم در تپ دستی و هم در حالت LRC (پخش به زمان همان خط می‌پرد).
- چون روی بوم رسم می‌شود، در خروجی WebM و MP4 (ASS با `\frx`) هم دیده می‌شود.

   پریست دوم: **«✨ کلمه‌به‌کلمه از پایین»** — کلمات یکی‌یکی از پایین بالا می‌آیند و خط رو به بالا خارج می‌شود؛ کلمه‌ی بین `*ستاره*` زرد و درشت و درخشان می‌شود و هیچ کادر تیره‌ای روی کلیپ نمی‌افتد.

۲. **استودیوی مستقل مکعب:** `/static/cube-studio/index.html` — فایل صوتی و متن لیریکس را بدهید، «▶ پخش و رندر» را بزنید و در پایان با «📥 خروجی ویدیویی (WebM)» کلیپ مکعب را بگیرید. اگر متن تایم‌استمپ `[mm:ss.xx]` داشته باشد همان رعایت می‌شود، وگرنه خطوط خودکار روی طول آهنگ تقسیم می‌شوند.

موتور مکعب و ذرات یک پیاده‌سازی مشترک است: `static/js/cube/CubeRenderer.js` و `static/js/cube/ParticleSystem.js`. به‌صورت پیش‌فرض `rotationMode: "bottom_up"` (هر خط ۹۰ درجه رو به بالا) و `singleFace: true` (فقط وجه خط جاری) است؛ برای چرخش متنوع با نسبت طلایی `rotationMode: "free"` بدهید.

### تست مکعب

```bash
node tests/cube_preview.test.mjs        # تست رفتاری مکعب بدون مرورگر (۱۲ سنجه)
node tests/word_reveal.test.mjs         # تست موتور کلمه‌به‌کلمه (کد واقعی studio.html)
python -m unittest discover -s tests    # ۳۶ تست یکپارچگی استودیو + افزونه‌های افکت
```

## افزودن افکت جدید (پلاگین)

لایه‌های افکت از `backend/effects/` کشف می‌شوند؛ برای افزودن افکت تازه نیازی به تغییر رندرکننده نیست:

۱. `backend/effects/<effect_id>.py` بسازید (نام فایل باید با `id` یکی باشد) و `EFFECT_SPEC` + `build_events()` + `render_ass()` را پیاده کنید.
۲. `static/js/effects/<effect_id>.js` با تابع `renderPreview(ctx, layer, timeSeconds, state, runtime)` بسازید تا پیش‌نمایش زنده هم داشته باشد.
۳. `/api/effects` خودش پلاگین را به مرورگر معرفی می‌کند و کنترل‌هایش در «مدیر لایه‌های افکت» ساخته می‌شود. جزئیات کامل: `docs_effects.md`.

## رندر نهایی از جدول

۱. آهنگ، پس‌زمینه، لیریکس و افکت‌ها را انتخاب/تنظیم کنید. ۲. در جدول، زمان شروع یا پایان را مستقیم وارد کنید یا کنار فیلد `+ / −` را بزنید؛ هر بار یک میلی‌ثانیه جابه‌جا می‌شود. کلیدهای `+`, `-`, `↑`, `↓` همان تغییر را انجام می‌دهند. ۳. دکمه‌ی «رندر نهایی FFmpeg + ذخیره MP4» را بزنید. پیشرفت رندر در همان بخش دیده می‌شود. ۴. در صورت فعال بودن گزینه‌ی ZIP (پیش‌فرض)، فایل کامل ZIP برای دانلود آماده می‌شود؛ MP4 هم در کارت پیش‌نمایش خروجی موجود است. گزینه را خاموش کنید تا فقط MP4 دانلود شود.

دکمه‌ی زیر بوم صرفاً ضبط سریع canvas مرورگر (WebM) است و با رندر نهایی FFmpeg فرق دارد.

## ZIP و انتقال پروژه

روی «دانلود ZIP کامل پروژه» بزنید؛ یا گزینه‌ی ساخت ZIP همراه رندر را فعال بگذارید. ZIP ساختار خودبسنده دارد:

```text
<project>/
├── project.json
├── README.txt
├── lyrics.txt
├── media/audio/...
├── media/background/...
├── media/overlays/...
├── media/mask/mask.png        # اگر ماسک استفاده شده باشد
└── renders/<output>.mp4       # بعد از رندر نهایی
```

`project.json` تنظیمات رندر و مسیر نسبی رسانه‌ها را نگه می‌دارد. برای رندر مجدد در PC، ZIP را استخراج کنید و پوشه‌ی پروژه را در `apps/3-LYRAX-CLIP-STUDIO/projects/` قرار دهید؛ سپس از ریشه‌ی برنامه اجرا کنید:

```bash
./render.sh "projects/<project-name>"
```

برای نگهداری ZIP روی گوشی یا PC از دانلود مرورگر استفاده کنید. در مرورگرهای پشتیبان File System Access API می‌توانید از تب بایگانی پوشه‌ی مقصد را نیز انتخاب کنید.

## اجرای دستی با محیط مجازی

```bash
python3 -m venv .venv
. .venv/bin/activate                  # Windows: .venv\\Scripts\\activate
python -m pip install -r requirements.txt
python app.py
```

سپس `http://127.0.0.1:5000` را باز کنید. سرور روی `0.0.0.0:5000` گوش می‌دهد تا از مرورگر همان دستگاه/شبکه‌ی محلی قابل دسترسی باشد. از سرور توسعه برای انتشار عمومی اینترنت استفاده نکنید.

## جزئیات فنی

- FFmpeg از بسته‌ی `imageio-ffmpeg` تأمین می‌شود؛ خروجی پیش‌فرض MP4، کدک H.264/AAC است.
- پوشه‌ی `projects/` برای داده‌ی کاری محلی است؛ ZIP خروجی نسخه‌ی قابل‌انتقال را نگه می‌دارد.
- مستندات معماری افزونه‌ها و Lightning: `docs_effects.md` و `docs_lightning.md`.
- مکعب سه‌بعدی لیریکس: `static/js/cube/` (موتور مشترک)، `static/css/cube.css` و صفحه‌ی مستقل `static/cube-studio/` — راهنمای فارسی: `docs_cube_3d_fa.md`.
