# 🎲 استودیوی مکعب سه‌بعدی لیراکس (LyraX 3D Cube)

این پوشه همان بسته‌ی «lyrax-3d-cube» است که داخل برنامه‌ی لیراکس قرار گرفته است:

- **آدرس صفحه:** `/static/cube-studio/index.html` (لینک آن در هدر استودیو: «🎲 استودیوی مکعب لیریکس»)
- **ورودی:** فایل صوتی (MP3/WAV) + متن لیریکس؛ هم با تایم‌استمپ `[mm:ss.xx]` و هم متن خام (تقسیم خودکار روی طول آهنگ).
- **خروجی:** ویدیوی WebM (۳۰ فریم، رزولوشن ۱۰۸۰×۱۹۲۰) با دکمه‌ی «📥 خروجی ویدیویی (WebM)».
- **موتور مکعب/ذرات:** همان ماژول مشترک استودیو (`/static/js/cube/CubeRenderer.js` و `ParticleSystem.js`) تا ظاهر پیش‌نمایش استودیو و این صفحه یکی باشد.
- در خود استودیو (تب ۱) به‌عنوان پریست «🎲 مکعب چرخان از پایین به بالا» در منوی استایل لیریکس انتخاب می‌شود؛ مکعب روی بوم/کلیپ رسم می‌شود (پنل جداگانه‌ای روی کلیپ نمی‌افتد).

## کلیدها

| کلید | کار |
| --- | --- |
| `Space` / `Enter` / `→` / `↓` | خط بعدی (مکعب از پایین به بالا می‌چرخد) |
| `←` / `↑` | خط قبلی |

فقط **وجه خط جاری** متن دارد و کلمه‌های بین `*ستاره*` روی وجه زرد/درشت (`.lyra-hl`) نمایش داده می‌شوند.
