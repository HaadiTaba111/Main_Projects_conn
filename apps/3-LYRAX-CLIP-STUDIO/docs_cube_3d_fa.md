# 🎲 مکعب سه‌بعدی لیریکس (LyraX Cube) — راهنمای فارسی

داداش، بسته‌ی «مکعب سه‌بعدی لیریکس» + بسته‌ی «لیراکس بهینه‌شده» که روی گیت‌هاب گذاشتی، حالا **داخل خود برنامه‌ی لیراکس** است.

جای مکعب این است (نسخه‌ی نهایی):

- **داخل استودیو، به‌عنوان یک پریست در منوی «✨ استایل انیمیشن و ترنزیشن لیریکس»** — «🎲 مکعب چرخان از پایین به بالا». دیگر هیچ پنل جداگانه‌ای روی کلیپ نمی‌افتد؛ مکعب روی خودِ بوم/کلیپ رسم می‌شود و در خروجی ویدیو هم هست.
- **صفحه‌ی مستقل مکعب** برای کار اختصاصی با آهنگ و خروجی WebM.
- موتور مکعب در ماژول خودش: `static/js/cube/`.

---

## ۱. مکعب داخل استودیو (به‌عنوان پریست استایل لیریکس)

۱. برنامه را باز کن (`http://127.0.0.1:5000`).
۲. تب «📺 ۱. ادیتور و سینک» → کادر «✨ استایل انیمیشن و ترنزیشن لیریکس» → گزینه‌ی
   **«🎲 مکعب چرخان از پایین به بالا»** (هر خط از پایین بالا می‌آید).
۳. متن لیریکس را بده و «▶️ شروع ضبط زنده» را بزن.

از این لحظه:

- **فقط وجه خط جاری متن دارد**؛ بقیه‌ی وجه‌های مکعب خالی می‌مانند (همان «فقط صفحه خط لیریکس با آهنگ»).
- با هر خط، مکعب **۹۰ درجه رو به بالا** می‌چرخد: خط جاری رو به بالا خارج می‌شود و خط بعد از **پایین** می‌آید.
- **با زدن کلید، لیریکس بعدی می‌آید:** `Space` / `Enter` / `→` / `↓` = خط بعد، `←` / `↑` = خط قبل.
  در حالت **LRC تایم‌دار** هم کلید کار می‌کند: پخش به زمان همان خط می‌پرد (نه اینکه فقط در حالت تپ دستی کار کند).
  دکمه‌های «⏩ خط بعد» / «⏪ خط قبل» و دکمه‌ی بزرگ تپ روی گوشی هم همین کار را می‌کنند.
- چون مکعب روی بوم رسم می‌شود، **در کلیپ ضبط‌شده (WebM) و در خروجی FFmpeg هم دیده می‌شود**
  (در ASS معادل چرخش `\frx` حول محور X با خروج رو به بالا).

### پرست «✨ کلمه‌به‌کلمه از پایین» (Word Reveal)

در همان منوی استایل، گزینه‌ی «✨ کلمه‌به‌کلمه از پایین» هم هست:

- کلمات یکی‌یکی از **پایین بالا** می‌آیند، خط که تمام شد همه **رو به بالا** خارج می‌شوند.
- کلمه‌ای که بین `*ستاره*` بگذاری، زرد و درشت و درخشان نمایش داده می‌شود:
  `این یک *تست* است برای *لایراکس*`
- هیچ کادر تیره‌ای پشت متن کشیده نمی‌شود؛ **کلیپ پشت کلمات دیده می‌شود**.

## ۲. استودیوی مستقل مکعب (با خروجی ویدیو)

آدرس: `http://127.0.0.1:5000/static/cube-studio/index.html`

۰. فقط همین صفحه‌ی خط لیریکس با آهنگ است: استیج مکعب + کادر لیریکس + پخش صدا.
۱. فایل صوتی را انتخاب کن (MP3/WAV).
۲. متن لیریکس را در کادر بگذار؛ دو حالت دارد:
   - با تایم‌استمپ: `[00:12.34] متن خط`
   - بدون تایم: خط‌ها خودکار روی طول آهنگ پخش می‌شوند.
۳. «▶ پخش و رندر» → موسیقی پخش می‌شود، مکعب می‌چرخد و حلقه‌های اکولایزر با صدا تپش می‌کنند.
   با `Space`/`→` خط بعدی و با `←` خط قبلی می‌آید (همان چرخش از پایین به بالا).
۴. «📥 خروجی ویدیویی (WebM)» → از ابتدای آهنگ ضبط می‌کند و فایل `lyrax-cube-export.webm` (۱۰۸۰×۱۹۲۰، ۳۰fps) دانلود می‌شود.
۵. «⏹ وقف» برای توقف.

> نکته: ضبط ویدیویی به `canvas.captureStream` و `MediaRecorder` مرورگر نیاز دارد؛ در کروم/ادج اندروید و دسکتاپ کار می‌کند. اگر مرورگر قدیمی باشد فقط پیش‌نمایش کار می‌کند.

## ۳. این چطور داخل برنامه جا داده شد؟

| بخش | مسیر |
| --- | --- |
| موتور مشترک مکعب (۶ وجه، چرخش، رنگ، اندازه) | `static/js/cube/CubeRenderer.js` |
| ذرات پس‌زمینه و حلقه‌های اکولایزر | `static/js/cube/ParticleSystem.js` |
| پل سینک با استودیو (`window.LyraXCube` + رویدادهای `lyrax:line` / `lyrax:lines`) | `static/js/cube/cube-preview.js` |
| استایل مکعب + کلمه‌ی ویژه (`.lyra-hl`) | `static/css/cube.css` |
| صفحه‌ی مستقل مکعب + پخش/خروجی WebM | `static/cube-studio/` |
| پریست «مکعب چرخان از پایین به بالا» + هوک خط جاری | `studio.html` و `templates/index.html` |
| پریست «کلمه‌به‌کلمه از پایین» (WordRevealEngine) | `studio.html` و `templates/index.html` |
| نگاشت خروجی ASS برای هر دو پریست | `backend/renderers.py` |

**دو نکته‌ی فنی:**

۱. زاویه‌ی چرخش هر خط با **نسبت طلایی** حساب می‌شود (`index * 137.5`)، یعنی چرخش هر خط متفاوت به نظر می‌رسد ولی همیشه **قطعی و تکرارپذیر** است؛ پس محیط مرورگر و رندر بک‌اند یک نتیجه می‌دهند.
۲. اگر می‌خواهی بدون مکعب کار کنی، در منوی استایل یکی از پریست‌های دیگر (کارائوکه/نئون/…) را انتخاب کن؛ هیچ بخش دیگری از استودیو به مکعب وابسته نیست (خطای مکعب هرگز رندر یا سینک را متوقف نمی‌کند).

## ۴. تست‌ها

```bash
node tests/cube_preview.test.mjs        # ۱۱ سنجه: سینک خطوط، پرش، رویدادها، رنگ/اندازه، localStorage
python -m unittest discover -s tests    # تست یکپارچگی استودیو + پلاگین‌های افکت (۳۰ تست)
```

تست‌های یکپارچگی بررسی می‌کنند که هر دو فایل `studio.html` و `templates/index.html` پریست‌های «مکعب از پایین به بالا» و «کلمه‌به‌کلمه»، موتور `WordRevealEngine`، هوک خط جاری و تایمینگ چرخش مکعب زیرنویس (۰.۸۵ ثانیه) را داشته باشند و پنل داکی‌شده‌ی قدیمی برنگردد.

## ۴. حالت‌های موتور مکعب (برای استفاده در کد)

```js
new CubeRenderer(cubeEl, {
  rotationMode: "bottom_up",  // پیش‌فرض: هر خط ۹۰ درجه رو به بالا (خط بعد از پایین می‌آید)
  singleFace: true,           // پیش‌فرض: فقط وجه خط جاری متن دارد
  size: 380, color: "#ff0055", textColor: "#ffffff"
});
```

- `rotationMode: "free"` همان چرخش متنوع با نسبت طلایی است (تکرارپذیر)، ولی باز هم تک‌وجهی.
- `visibleFaceAt(rotation)` وجه روبه‌رو را برمی‌گرداند؛ ترتیب چرخش پایین‌به‌بالا:
  `front → bottom → back → top → front` (هر قدم ۹۰ درجه).
- کلمه‌ی `*ویژه*` روی وجه، با `em.lyra-hl` (زرد/درشت/درخشان) رندر می‌شود.
