### مغز هوشمند آفلاین دوزبانه با چشم (بینایی)، دست (کنترل و اجرا) و پا (دروازه ارتباط موبایل اندروید)

سلام داداش هادی عزیز! این پروژه نسخه نهایی، کاملاً ماژولار، پارامتریک و بهینه‌شده سیستم عامل و ایجنت خودکار شخصی توئه که تمام قطعات پراکنده رو یکجا، دقیق و بدون خطا جمع‌آوری کرده.

## 🌟 معماری سیستم: مغز دوگانه (Dual-Brain Engine)

```
                  ┌──────────────────────────────────────────────────┐
                  │                کاربر (هادی / موبایل)              │
                  └─────────────────────────┬────────────────────────┘
                                            │ (فارسی)
                                            ▼
                  ┌──────────────────────────────────────────────────┐
                  │    🧠 مغز هماهنگ‌کننده و مترجم: Qwen 2.5          │
                  │   - درک زبان فارسی، هماهنگی حواس و ابزارها        │
                  │   - ترجمه پرامپت‌ها به انگلیسی فنی با حفظ کد      │
                  └─────────────┬──────────────────────┬─────────────┘
                                │                      │
                 (تسک‌های عادی) │                      │ (مسائل سنگین/کد/ریاضی)
                                ▼                      ▼
                    ┌──────────────────────┐   ┌──────────────────────────────────┐
                    │  ⚡ پاسخ مستقیم Qwen │   │  🔬 مغز استدلال عمیق: DeepSeek R1 │
                    └──────────────────────┘   │  - تفکر زنجیره‌ای (<think>)      │
                                               │  - حل مسئله و تولید کد به لاتین   │
                                               └────────────────┬─────────────────┘
                                                                │ (پاسخ انگلیسی)
                                                                ▼
                                               ┌──────────────────────────────────┐

                                               └────────────────┬─────────────────┘
                                                                │
                                                                ▼
                                                [پاسخ نهایی روان و فارسی به کاربر]
```

## 🧩 ماژول‌های چهارگانه + لایهٔ ابزار (بخش 🧰 در پایین)

### ۱. 🧠 مغز و حافظه (Brain & Memory)
* **DualBrainRouter:** سوییچ خودکار یا دستی بین Qwen و DeepSeek R1 بر اساس نوع تسک یا کلمات کلیدی.
* **TranslatorBridge:** ترجمه دقیق پرامپت‌های فارسی به انگلیسی فنی و ترجمه پاسخ به فارسی بدون دستکاری در کدها و فرمول‌ها.
* **MemoryEngine:** ذخیره تاریخچه، تجربیات و تسک‌ها در SQLite به همراه **الگوریتم DSA Fade-Not-Forget** ($\lambda=0.15, \gamma=0.4, w_{min}=0.15$).
* **ApprovalGuard:** محافظ امنیتی برای جلوگیری از اجرای فرامین خطرناک (`rm -rf` و ...) با قابلیت پیش‌نمایش تغییرات (Diff) و تایید کاربر.

### ۲. 👁️ چشم و بینایی (Eyes)
* **ScreenCaptureEngine:** گرفتن اسکرین‌شات پرسرعت از دسکتاپ، مانیتورهای چندگانه یا پنجره فعال با پشتیبانی از `mss` و `PIL` و حالت Fallback در سرورهای هدلس.
* **VLMVisionClient:** اتصال به مدل‌های بینایی چندحالته (مانند `qwen2-vl:7b` یا `llava`).
* **VisualLocator:** تشخیص مختصات دکمه‌ها و عناصر گرافیکی صفحه و تبدیل به پیکسل‌های واقعی `(x, y)` جهت کلیک ماوس.

### ۳. 🖐️ دست‌ها و ابزارها (Hands)
* **InputController:** حرکت نرم ماوس، کلیک چپ/راست، اسکرول و تایپ متن (با استفاده از مکانیزم Clipboard برای پشتیبانی ۱۰۰٪ بدون اشکال از حروف و کلمات فارسی).
* **SafeCommandExecutor:** اجرای دستورات شل با سقف زمانی (Timeout) و ایزوله‌سازی دایرکتوری.
* **SafeFileManager:** خواندن، نوشتن اتمیک، ویرایش هوشمند فایل‌ها و ساخت بکاپ‌های خودکار با مهر زمانی (`.qwen_hands_eyes/backups`).
* **WebOperator:** ایجنت جستجو در اینترنت (DuckDuckGo HTML) و دریافت/خلاصه‌سازی صفحات وب بدون نیاز به ابزار خارجی.

### ۴. 🦶 پا و دروازه موبایل اندروید (Feet)
* **APIGatewayServer:** سرور استاندارد REST API و WebSocket جهت اتصال اپلیکیشن اندروید یا ریموت.
* **StaticIPHelper:** شناسایی خودکار IP شبکه داخلی (LAN)، IP استاتیک یا عمومی اینترنت جهت کانفیگ سریع گوشی.
* **اندپوینت‌های استاندارد:**
  - `POST /api/v1/chat`: گفتگو با مغز دوگانه (Qwen + DeepSeek R1).
  - `GET /api/v1/eyes/snapshot`: دریافت اسکرین‌شات و تحلیل بینایی.
  - `POST /api/v1/hands/action`: فرمان اجرای اکشن ماوس، کیبورد یا شل.
  - `POST /api/v1/brain/route`: تغییر حالت مدل به صورت آنی.
  - `POST /api/v1/search`: جستجوی زنده در وب.

## 🚀 نحوه نصب و راه‌اندازی (روی سیستم RTX 3060 هادی)

### ۱. نصب پیش‌نیازها
در پوشه پروژه دستور زیر را اجرا کنید (یا روی `install.bat` دابل‌کلیک کنید):
```bash
pip install -r requirements.txt
```

### ۲. اجرای مدل‌ها در Ollama
```bash
# مدل اصلی فارسی و هماهنگ‌کننده
ollama run qwen2.5:7b-instruct-q4_K_M

# مدل استدلال عمیق
ollama run deepseek-r1:7b

# مدل بینایی (اختیاری برای چشم)
ollama run qwen2-vl:7b
```

### ۳. اجرای سیستم
روی فایل `start_agent.bat` دابل کلیک کنید یا در ترمینال بزنید:
```bash
python main.py --config config/config.json --port 8765
```

داشبورد زیبا و مدرن وب روی آدرس زیر در دسترس خواهد بود:
👉 **`http://localhost:8765`**

## 📱 اتصال اپلیکیشن موبایل اندروید (Feet)

1. در فایل `config/config.json`، مقدار `static_ip` را روی IP سیستم خود (یا IP استاتیک/دامنه تونل) بگذارید.
2. در اپلیکیشن اندروید، آدرس سرور را برابر با `http://192.168.1.X:8765` (یا آدرس استاتیک) قرار دهید.
3. تمام درخواست‌ها با امنیت توکن و به صورت بهینه برای موبایل پردازش می‌شوند.

## ⚙️ گزینه‌های خط فرمان (CLI Flags)

| فلگ | توضیح |
|---|---|
| `--config <path>` | تعیین مسیر فایل پیکربندی (پیش‌فرض: `config/config.json`) |
| `--mode <name>` | حالت اجرا: `dual_brain`, `qwen_direct`, `deepseek_direct`, `api_bridge` |
| `--port <number>` | شماره پورت سرور داشبورد و API (پیش‌فرض: `8765`) |
| `--dry-run` | اجرای شبیه‌سازی ماوس و کیبورد بدون ارسال کلیک فیزیکی |
| `--no-server` | اجرای تعاملی در ترمینال بدون راه‌اندازی وب‌سرور |
| `--server-only` | فقط وب‌سرور و API را بالا بیاورد (بدون چت تعاملی ترمینال) |
| `--host <ip>` | آدرس اتصال سرور (مثلاً `0.0.0.0` برای دسترسی موبایل) |
| `--no-tools` | خاموش‌کردن لایهٔ ابزار SkyGround (حالت چت سادهٔ دو‌مغزی) |

## 🧰 ماژول پنجم: لایهٔ ابزار SkyGround (ادغام کد جدید «دست و چشم»)

فایل `core/skyground_tools.py` (برگرفته از ماژول SkyGround خودت) حالا داخل همین برنامه سیم‌کشی شده است:
مدل به‌جای دستور خام، «فراخوانی ابزار» می‌سازد و برنامه آن را از **دروازهٔ ایمنی** و **دفتر تجربه** عبور می‌دهد.

### چرخهٔ اجرا (هر قدم)

```
مدل (prompt ابزارها) → JSON فراخوانی → اعتبارسنجی قرارداد (حداکثر ۲ ترمیم)
   → دروازهٔ ایمنی (مسیر/فرمان/ریسک) → ApprovalGuard برای عمل پرمخاطره
   → اجرای واقعی ابزار → ثبت در ExperienceLog → قدم بعدی یا finish
```

### ابزارهای ثبت‌شده (۱۰ عدد)

| ابزار | ریسک | پشت آن |
|---|---|---|
| `list_dir` / `read_file` / `write_file` | کم / کم / **متوسط** | فایل‌سیستم، محدود به `workspace_root` |
| `run_shell` | **بالا** | Hands (پیش‌فرض `dry_run=true`) |
| `web_search` | کم | `WebOperator.search()` همان تب جستجوی وب |
| `screen_capture` | متوسط | `ScreenCaptureEngine` همان تب Eyes |
| `ui_action` | **بالا** | `InputController` (کلیک/تایپ/کلید/اسکرول) |
| `remember` / `recall` | کم | `ExperienceLog` (SQLite؛ thread-safe) |
| `finish` | — | پایان حلقه با پاسخ نهایی |

نکتهٔ امنیتی: مسیرهای نسبی همیشه داخل `workspace_root` حل می‌شوند و `..` بیرون از آن راه ندارد،
حتی اگر دروازهٔ ایمنی دور زده شود. هر عمل با ریسک متوسط/بالا (نوشتن فایل، فرمان، کنترل UI)
در تب «دست‌ها» برای تأیید صف می‌شود؛ بدون تأیید، رد و در گام‌ها با ⛔/🛡️ گزارش می‌شود.

### از داشبورد

تب **🧰 ایجنت ابزارها (SkyGround)** اضافه شده:
فهرست زندهٔ ابزارها (نام/پارامتر/ریسک/توضیح) + کادر اجرای وظیفه با نمایش تک‌تک گام‌ها و پاسخ نهایی.

### از ترمینال

```
/tools                 # فهرست ابزارها و مسیر فضای کاری
/agent خلاصه‌ای از فایل‌های پوشه در notes.txt بنویس
```

### API

| روت | روش | کار |
|---|---|---|
| `/api/v1/tools` | GET | فهرست ابزارها + نسخه + فضای کاری (`{ok, enabled, version, workspace, tools[]}`) |
| `/api/v1/agent/run` | POST | اجرای حلقهٔ ابزار با `{task \| message, system_prompt, history}` → `{ok, task, answer, steps[], stopped_early}` |
| `/api/v1/status` | GET | علاوه بر قبل، `tool_layer_enabled` و `tools[]` |

### تست‌ها

```
cd apps/5-QWEN-HANDS-EYES
python3 -m unittest discover -s tests -v     # ۳۲ تست: ۱۲ قدیمی + ۲۰ تست لایهٔ ابزار
python3 core/skyground_tools.py              # خودآزمایی خودِ ماژول: «همهٔ ۱۰ آزمون گذشت»
```

> اگر می‌خواهی همین برنامه بدون مدل محلی هم بالا بیاید و فقط داشبورد/API را ببینی:
> `python3 main.py --server-only --host 0.0.0.0 --port 7860`
