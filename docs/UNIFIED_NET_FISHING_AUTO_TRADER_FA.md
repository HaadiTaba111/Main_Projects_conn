## 🧭 ۱. مفهوم و فلسفه بنیادین «تور ماهیگیری» در ترید کریپتو

در تریدهای سنتی، تریدر یک اردر نقطه‌ای می‌گذارد؛ با کوچک‌ترین نوسان بازار، استاپ می‌خورد یا از بازار جا می‌ماند.

در **استراتژی تور ماهیگیری (Net Fishing Strategy)**:
> «ما دنبال پیش‌بینی دقیق جهت بازار نمی‌دویم؛ بلکه با ترکیب هوش ۵ پروژه‌ات، یک **تور چندسطحی نقدینگی (Ladder Grid)** در مسیر امواج نهنگ‌ها پهن می‌کنیم. قیمت به هر سمتی که موج بزند، در گره‌های تور می‌افتد و با برگشت موج، سودها به‌صورت خودکار درو (Harvest) می‌شوند!» 🌊🎣

## 🧩 ۲. تحلیل و تجمیع قابلیت‌های ۵ زیپ‌فایل و پروژه در این موتور

| نام پروژه / زیپ‌فایل | نقش اختصاصی در موتور تور ماهیگیری |
| :--- | :--- |
| **۱. `futures.zip` (Futures PWA پورت 8787)** | رابط کاربری سریع موبایل، چارت زنده، Kill Switch اضطراری و دیتای چندگانه ضدتحریم |
| **۲. `automated-crypto-trading-dashboard.zip` (پورت 3001)** | موتور خودکار باز/بسته‌شدن پوزیشن‌ها با حد سود/ضرر، مدیریت کیف‌پول مجازی و دیتابیس |
| **۳. `update-backend-frontend-integration.zip` (Adaptive Ratio Brain)** | **حسگر تله‌های نقدینگی (Trap Sensor):** تشخیص دستکاری نهنگ‌ها و واگرایی‌های حجم/RSI |
| **۴. `scrape-top-trader-wallets.zip` (Whale Tracker)** | **ردیاب وال‌ها:** مانیتورینگ سفارش‌های بالای ۵۰۰ هزار دلار و جهت پول هوشمند |
| **۵. `futures-scalp-lab` (Python Core Engine)** | محاسبات سنگین ریاضی، فرمول‌های ATR داینامیک، شبیه‌سازی مونت‌کارلو و مدیریت ریسک |

```bash

cd apps/futures-scalp-lab
python3 scalplab/net_fishing_engine.py
```

📌 **خروجی لحظه‌ای:**
- نمایش لایه‌های گره‌های تور در بالا و پایین قیمت مبنا.
- نمایش وضعیت صید شدن اردرها با نوسان مارکت.
- درو کردن سودهای کسب‌شده به تفکیک هر گره تور.
