# 📖 راهنمای کامل AgentRouter Hub

## معماری در یک نگاه
**مغز** = مدل اصلی (API یا Ollama) که برنامه‌ریزی و تصمیم می‌کند • **مترجم** = مدل واسط فارسی↔انگلیسی (مثلاً Qwen روی Ollama برای DeepSeek R1) • **چشم** = Parser الگوریتمیِ لاگ صفحه (دوربین فقط عنداللزوم) • **دست** = مجری الگوریتمی Shortcut/تایپ/ماوس با وایت‌لیست • **حافظه** = دیتابیس مهارت‌های داشبورد • **شما** = ناظر و صاحب دسترسی‌ها.

## ابزارها
| ابزار | فایل/مسیر | کار |
|---|---|---|
| داشبورد | `agent-router-dashboard/index.html` | رابط اصلی؛ فقط `python3 -m http.server 8000` |

## جریان‌های کاری اصلی
1. **سؤال فارسی به مدل خارجی:** تب ایجنت → مدل اصلی و مترجم را انتخاب کنید → اجرا (ترجمه→مدل→ترجمه، زنده در فعالیت زنده).
2. **کار روتین بدون مغز:** تب حافظه → پلی‌بوک اولیه از مغز، یا آموزش توسط خودم، یا یادگیری از تجربه → چشم وضعیت را (دقیق/فازی) می‌شناسد و دست اجرا می‌کند.
3. **زنجیره چند مدلی:** تب ایجنت، کارت زنجیره → پریست (از جمله «چشم → DeepSeek → منتقد → مترجم») یا زنجیره دستی؛ هر قدم مدل+نقش جدا.
4. **کنترل و ایمنی:** دسترسی‌ها و پروفایل‌ها (تب دسترسی‌ها) • STOP اضطراری قرمز یا Ctrl+Shift+E • نگهبان لوپ در فعالیت زنده • حد RAM برای ایجنت.

## راهنمای هر بخش داخل داشبورد
در هر تب دکمه «؟ راهنمای این بخش» هست و کلید **F1** راهنمای همان قسمت را باز می‌کند. تب «📖 راهنما و مستندات» همه را یک‌جا با جستجو دارد.

## کلیدهای میانبر
| کلید | کار |
|---|---|
| `F1` | راهنمای بخش فعلی |
| `Ctrl+Shift+E` | STOP اضطراری / خروج از آن |
| `Ctrl+Enter` (در چت) | ارسال پیام |
