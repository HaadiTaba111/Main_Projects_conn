# AgentRouter Hub — داشبورد مدیریت API

داشبورد فارسی و راست‌چین برای مدیریت APIهایی که از **Agent Router** می‌گیرید (سازگار با OpenAI API).

## اجرا
```bash
cd agent-router-dashboard
python3 -m http.server 8000
# باز کنید: http://localhost:8000
```
یا فایل `index.html` را مستقیم در مرورگر باز کنید.

## امکانات
- **مدیریت چند کلید API**: افزودن/ویرایش/حذف، کلید فعال، Base URL جدا برای هر کلید، کپی و ماسک کلید
- **تست اتصال و همگام‌سازی مدل‌ها** از `GET /v1/models` همراه با سنجش Latency
- **آزمایشگاه چت Streaming** با تنظیم مدل، System Prompt، Temperature و Max Tokens + دکمه توقف
- **داشبورد آماری**: تعداد کلید/مدل/درخواست، توکن مصرفی، نمودار ۷ روز اخیر، حالت دمو
- **لاگ کامل درخواست‌ها** (موفق/خطا، زمان پاسخ، توکن) با خروجی JSON
- **تاریخچه مکالمات** با کپی پاسخ و خروجی چت
- **نمونه‌کد آماده** cURL / Python / JavaScript بر اساس کلید و مدل فعال
- **بکاپ‌گیری و بازیابی** همه داده‌ها (JSON) و ریست کامل
- کاملاً **بدون بک‌اند**: کلیدها فقط در LocalStorage مرورگر شما می‌مانند.

## نکات
- Base URL پیش‌فرض: `https://agentrouter.org/v1`
- اگر مرورگر خطای CORS داد، یعنی سرویس برای دامنه شما CORS باز نکرده؛ از یک پروکسی/بک‌اند واسط استفاده و آدرس آن را به‌عنوان Base URL وارد کنید.
- برآورد توکن در حالت Streaming (وقتی سرور usage نفرستد) تقریبی است.

## 👁️⌨️ چشم و دست (تب جدا — لاگ‌محور و Shortcut‌محور)
- **چشم ≠ دوربین:** اولویت با **فایل لاگ صفحه** است (`{"type":"page","url":...,"buttons":[...],"inputs":[...],"errors":[...]}` به‌صورت JSON-lines). داشبورد لاگ را محلی Parse/dedupe و خلاصه می‌کند و فقط خلاصه را برای مدل می‌فرستد → سریع‌تر و کم‌توکن‌تر. DOM/HTML رتبه دوم، اسکرین‌شات سوم و **دوربین فقط عنداللزوم** است.
- **دست ≠ کلیک شانسی:** اولویت با **Shortcut**هاست (`ctrl+l`, `Tab`, `ctrl+shift+t` و...) از طریق `xdotool` روی اوبونتو؛ ماکرو و تایپ متن هم هست. پیشنهاد Shortcut مدل، قبل از اجرا نیاز به تأیید انسان دارد.

### اجرا روی اوبونتو 22.04
```bash
cd agent-router-dashboard/eye-hand-service
bash install-ubuntu22.sh          # xdotool + سرویس systemd کاربر روی پورت 8765
python3 ../tools/make_sample_page_log.py   # لاگ نمونه در /tmp/page.log (اختیاری، برای تست)
systemctl --user status eye-hand.service
```
بعد در داشبورد: تب **«چشم و دست»** → «خواندن زنده لاگ از اوبونتو» → «پرسیدن از مدل» → Shortcut پیشنهادی را تأیید و اجرا کنید.
لاگ واقعی صفحه را هر تولیدکننده‌ای می‌تواند بنویسد (اکستنشن/اسکریپت Playwright/Puppeteer که بعد از هر تغییر صفحه، یک خط JSON بالا را append کند).

## 🧩 معماری ماژولار (API + Ollama + مترجم + دسترسی + مانیتور زنده)
هر قابلیت یک ماژول جدا در `modules/` است: `permissions.js` (دسترسی/پروفایل)، `activity.js` (مانیتور زنده)، `providers.js` (API+Ollama+جستجو)، `agent.js` (ایجنت/مترجم/ماوس)، `modules-ui.js` (رجیستری ماژول‌ها). تب‌ها هم موضوعی‌اند تا داشبورد شلوغ نشود: ایجنت | فعالیت زنده | ماژول‌ها | دسترسی‌ها | چشم‌ودست | ...

- **دو مدل هم‌زمان:** در تب «ایجنت و روتینگ مدل‌ها» مدل اصلی و مترجم را جدا انتخاب می‌کنید؛ پیشوند `api:` یعنی AgentRouter و `ollama:` یعنی Ollama محلی (`http://127.0.0.1:11434`). مثال: سؤال فارسی → مترجم (مثلاً Qwen روی Ollama) → DeepSeek R1 (API) → مترجم → جواب فارسی.
- **دسترسی‌ها از شما اجازه می‌گیرند:** همه دسترسی‌ها پیش‌فرض خاموش‌اند؛ ایجنت هنگام نیاز مودال «فعال کن / فقط همین بار / رد» نشان می‌دهد.
- **پروفایل دسترسی:** در تب «دسترسی‌ها و پروفایل‌ها» پروفایل آماده (فقط مشاهده / مرورگر با Shortcut / تحقیق اینترنتی / کنترل کامل) انتخاب کنید یا از وضعیت فعلی، پروفایل با نام دلخواه بسازید و بعداً با یک انتخاب اعمالش کنید.
- **فعالیت زنده:** تب «فعالیت زنده» + نشانگر بالای داشبورد نشان می‌دهد ایجنت الان در کدام مرحله است (ترجمه، جستجو، فکرکردن مدل، Shortcut...) و چه کرده/کجا خطا خورده.
- **جستجوی اینترنت:** ماژول جدا و دسترسی‌دار؛ از `POST /search` سرویس اوبونتو (DuckDuckGo Lite) انجام می‌شود و نتایج قبل از مدل اصلی به او داده می‌شود.
- اسکرین‌شات/دوربین/ماوس ماژول‌های جدا و پیش‌فرض خاموش‌اند (در تب ماژول‌ها).
