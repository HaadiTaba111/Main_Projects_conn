⚡ شروع سریع
  1. از agentrouter.org یک API Key بگیرید.
  2. با دکمه «افزودن کلید» آن را اضافه کنید.
  3. روی «تست و همگام‌سازی مدل‌ها» بزنید.
  4. در آزمایشگاه چت، مدل را انتخاب و گفتگو کنید.
