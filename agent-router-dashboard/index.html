      🔀 چشم و دست به چه کسی وصل‌اند؟
      
چشم → Parser (بدون مدل) → خلاصه ساخت‌یافته → اگر لازم بود مترجم (فقط متن داخل خلاصه را انگلیسی می‌کند) → مدل اصلی تصمیم‌گیر (مثل DeepSeek R1) که ACTION می‌دهد → ACTION بدون ترجمه و پس از اعتبارسنجی+اجازه شما → دست. توضیح تصمیم برای شما برعکس همین مسیر را با مترجم فارسی می‌شود. مترجم هرگز دست را کنترل نمی‌کند.

      

      

      👁️ چشم — اول لاگ صفحه، دوربین فقط عنداللزوم
      
ترتیب سرعت: ۱) لاگ صفحه (سریع‌ترین) ← ۲) خلاصه DOM/متن صفحه ← ۳) اسکرین‌شات ← ۴) دوربین (فقط وقتی لاگ چیزی نشان نمی‌دهد). خامِ کامل برای مدل ارسال نمی‌شود؛ اول همین‌جا خلاصه و dedupe می‌شود تا هم سریع باشد هم توکن کم مصرف شود.

🧠 مهارت‌ها (روتین‌های آموخته‌شده)
      
چطور یاد می‌گیرد؟ وقتی چشم یک وضعیت صفحه را می‌بیند، مدل تصمیم می‌گیرد و شما ACTION را اجرا و نتیجه را تأیید می‌کنید، آن وضعیت+عمل به‌صورت «مهارت» ذخیره می‌شود. دفعه بعد همان وضعیت، داشبورد مهارت را پیشنهاد می‌دهد و اصلاً مدل اصلی صدا زده نمی‌شود — مگر خودتان بگویید «از مغز بپرس». مهارتِ با حداقل ۱ اجرای موفق، «قابل اعتماد» می‌شود.

🤖 ایجنت دو مدله — اشتراک API + Ollama با مترجم واسط
      
مثال: سؤال فارسی شما ← مدل مترجم (فارسی↔انگلیسی) ← مدل اصلی مثل DeepSeek R1 که فارسی بلد نیست ← جواب انگلیسی ← مترجم ← پاسخ فارسی. هر مرحله زنده در تب «فعالیت زنده» دیده می‌شود. اگر متن فارسی نباشد، ترجمه خودکار رد می‌شود.

      ⛓️ زنجیره ایجنت‌ها — خروجی هر ایجنت، ورودی بعدی است
      
پریست‌ها: «ترجمه+DeepSeek» • «چشم ← تحلیل ← پیشنهاد دست» • «جستجو ← تحلیل ← نقد». هر قدم مدل و نقش جدا دارد و در فعالیت زنده دیده می‌شود. قدم «پیشنهاد دست» هیچ‌وقت خودش اجرا نمی‌کند؛ ACTION فقط داخل کادر Shortcut قرار می‌گیرد تا شما اجرا کنید.
